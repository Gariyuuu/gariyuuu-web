## App routes (`src/app/`)

| Path | What it is |
|---|---|
| `layout.tsx` | Root layout. Mounts `MatrixRain` and `BootIntro` globally (every route), plus `Nav`/`Footer`. Sets the `Share_Tech_Mono` font and page metadata. |
| `page.tsx` | Landing page (`/`). |
| `globals.css` | The entire visual identity: CSS vars, Tailwind v4 `@theme inline` mapping, all keyframe animations (boot-crash, boot-flood-shake, boot-glitch). See `UI_SYSTEM.md`. |
| `about/page.tsx` | Résumé/bio (`/about`). Content is hardcoded arrays in this file — edit directly, no CMS. |
| `projects/page.tsx` | Full projects grid (`/projects`), reads `src/lib/projects.ts`. |
| `chat/page.tsx` | Chat demo page shell (`/chat`), renders `<ChatWidget/>`. |
| `dashboard/page.tsx` | Server component gate: checks session cookie, renders login form or the dashboard. |
| `api/chat/route.ts` | Public chat proxy → AI platform `/chat/completions`, SSE passthrough. |
| `api/dashboard/auth/route.ts` | Validates email+password, issues signed session cookie. |
| `api/dashboard/usage/route.ts` | Validates session, proxies to AI platform `/admin/usage`. |
| `api/dashboard/logout/route.ts` | Clears the session cookie. |

## Components (`src/components/`)

| File | What it is |
|---|---|
| `boot-intro.tsx` | Full-screen boot animation, mounted site-wide. Client component. Contains the `BOOT_LINES`/`FLOOD_LINES`/`FLOOD_WINDOWS`/`CRASH_LINES`/`RECOVER_LINES` copy — edit here to change the boot-sequence text. |
| `matrix-rain.tsx` | Canvas-based falling-character background, site-wide. |
| `nav.tsx` | Top nav bar, hardcoded `links` array (Home/Projects/About/Chat Demo/Dashboard). |
| `footer.tsx` | Site footer, hardcoded social links. |
| `project-card.tsx` | Renders one `Project` (from `projects.ts`) as a card with screenshot/badge. |
| `chat-widget.tsx` | Chat UI + manual SSE parser (`parseSSE`), talks to `/api/chat`. |
| `dashboard-login-form.tsx` | Email+password form, posts to `/api/dashboard/auth`. |
| `usage-dashboard.tsx` | Fetches and renders `/api/dashboard/usage`, includes the hardcoded Qwen3-8B pricing constants used for the cost estimate. |

## Lib (`src/lib/`)

| File | What it is |
|---|---|
| `dashboard-auth.ts` | The entire dashboard auth primitive: HMAC session token creation/verification. No external deps beyond Node's `crypto`. Read this first for anything security-related. |
| `projects.ts` | The single source of truth for every project shown on `/` and `/projects` — the `Project` interface and the 26-entry `PROJECTS` array. |

## Config

| File | Note |
|---|---|
| `.env.example` | Every env var the app uses, with empty placeholder values. **This is the reference for what needs to be set** — see `SECURITY.md`/`DEPLOYMENT.md`. |
| `.env.local` | Real values, gitignored, never committed (verified). Not present in a fresh clone — must be created from `.env.example`. |
| `next.config.ts` | Minimal, default Next.js config. |
| `eslint.config.mjs` | Flat ESLint config. |
| `tsconfig.json` | Standard Next.js TS config. |
| `.vercel/` | Vercel project link (gitignored). Confirms deployment target — see `DEPLOYMENT.md`. |
